# 기술 아키텍처

## 엔진
Godot 4.x를 사용한다. 빠른 2D 지도 제작, Windows 내보내기, Steam 연동 확장, 데이터 중심 개발과 디버깅 편의성을 우선한다.

## 계층
- Presentation: 지도, HUD, 툴팁, 메뉴
- Application: 명령 큐, 턴 해결, 저장·불러오기
- Domain: Country, Province, Army, War, Treaty
- Data: JSON 또는 Resource 기반 시나리오·규칙
- Infrastructure: 파일 I/O, Steam, 로그, 성능 측정

## 턴 파이프라인
1. 플레이어와 AI 명령 수집
2. 명령 유효성 검증
3. 외교 행동 해결
4. 이동과 보급 계산
5. 전투 해결
6. 점령과 통제 변경
7. 경제·인구·안정도 갱신
8. 사건 처리
9. AI 평가 캐시 갱신
10. 저장용 스냅샷 생성

## AoCII 분석에서 채택할 패턴
- 지도·시나리오·국가 데이터의 외부 파일 분리
- Province 중심의 세계 모델
- 지도 확대 수준별 단순화 데이터
- AI의 건설·전쟁·전선 기능 분리
- 해상도별 UI 자산 대신 반응형 UI 테마 사용

## 채택하지 않을 패턴
- 단일 대형 게임 클래스
- 화면별 중복 UI 코드
- Java 직렬화에 종속된 저장
- 국가 관계를 단일 수치로 축약
- 예외 규칙을 계속 덧붙이는 AI
