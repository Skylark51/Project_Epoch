Project Epoch 도시 내정 대시보드 디자인 인계서 (Codex2용)

이번 변경의 범위
- 도시 더블클릭 화면을 현황 탭과 인력 배분 탭으로 구조화했다.
- 창 크기는 화면 크기에 비례하며 1024×576에서도 화면 밖으로 나가지 않는다.
- 인력 배분은 합계 100일 때만 적용할 수 있고, 균형·성장·방비 프리셋을 제공한다.
- 게임 규칙과 배치 구조는 안정화되어 있으므로 Codex2는 시각 디자인을 중심으로 수정한다.

교체 가능한 UI 에셋
- assets/ui/city_admin/population.svg
- assets/ui/city_admin/food.svg
- assets/ui/city_admin/production.svg
- assets/ui/city_admin/security.svg

에셋 계약
- 32×32 viewBox, 투명 배경, 내장 텍스트 없음
- 파일명을 유지하면 코드 변경 없이 교체 가능
- 18×18 표시에서도 의미가 구분되는 단순한 실루엣 유지
- 색은 SVG 안에서 바꿀 수 있으나 네 아이콘의 선 두께와 시점을 통일

레이아웃 계약
- 도시 상세 창은 화면 너비의 약 82%, 높이의 약 82%를 사용하며 최소 720×480, 최대 980×720이다.
- 첫 탭은 도시 3/4 미리보기와 핵심 수치 카드, 두 번째 탭은 인력 배분이다.
- 인력 배분의 labor/food/guard 키와 합계 100 검증을 변경하지 않는다.
- ui.city_detail_tabs, ui.city_allocation_spins, ui.city_allocation_total,
  ui.city_allocation_apply, ui.city_allocation_preset_buttons 테스트 계약을 유지한다.

디자인 개선 권장
- 현재 색상과 테두리는 기능 확인용이다. 과도한 금색, 두꺼운 테두리, 둥근 카드 느낌을 줄이고 시대감 있는 절제된 패널로 교체한다.
- 핵심 수치는 장식보다 읽기 순서를 우선한다.
- 현황 탭과 인력 배분 탭의 선택 상태가 한눈에 보여야 한다.
- 프리셋 추천은 강조하되 다른 프리셋과 직접 입력을 잠그지 않는다.
- 1024×576, 1280×720, 1920×1080에서 글자 잘림과 버튼 겹침을 확인한다.

검증
- 국가 선택 → 도시 개척 → 첫 건설 → 정착민 → 운영 사업 → 지도 도시 더블클릭
- 현황 탭에서 인구·식량·생산·방비 확인
- 인력 배분 탭에서 합계 100 미만/초과 시 적용 버튼 비활성 확인
- 세 프리셋과 직접 입력이 모두 작동하는지 확인
- res://ui_smoke_test.gd 실행 후 UI_SMOKE_OK 확인
