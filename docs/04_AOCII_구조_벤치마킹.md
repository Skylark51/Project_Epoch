# AoCII 구조 벤치마킹 기준

## 목표

Project Epoch는 Province 기반 역사 대전략 게임의 빠른 접근성과 반복 플레이 구조를 계승하되, 원작 코드·지도·그래픽·데이터를 사용하지 않는 독립 구현이다.

## 유지할 핵심 구조

1. **Province가 세계의 최소 단위**
   - 소유국, 인구, 경제, 개발도, 지형, 요새, 주둔군, 인접 Province를 가진다.
2. **시나리오 중심 시작 상태**
   - 시작 연도, 플레이 국가, 외교 관계, 전쟁 상태를 외부 데이터에서 읽는다.
3. **명령 제출 후 턴 실행**
   - 플레이어와 AI가 명령을 예약한 뒤 한 번에 처리한다.
4. **지도 자체가 핵심 인터페이스**
   - 정치·경제·인구·외교 관계를 동일한 Province 지도에서 전환한다.
5. **데이터와 로직 분리**
   - 국가, Province, 시나리오, 외교 초기값을 JSON으로 관리한다.

## 현재 턴 파이프라인

```text
플레이어 명령 예약
+ AI 전략 판단
→ 외교 단계
→ 모집 단계
→ 이동·전투 단계
→ 경제 단계
→ 성장 단계
→ 외교 관계 변화
→ 날짜 진행
```

## 원작에서 개선할 부분

- 즉시 실행 대신 명령 큐를 명확히 시각화한다.
- 공격 전 전쟁 상태와 관계 수치를 확인할 수 있게 한다.
- AI를 외교·모집·군사 계획으로 분리한다.
- 전투 결과에 지형, 요새, 기술, 개발도를 반영한다.
- 경제에서 세입과 군대 유지비를 분리해 표시한다.
- 기능이 늘어나도 `GameState` 하나에 모든 판단이 쌓이지 않도록 모듈화한다.

## 독립 구현 원칙

- 역컴파일한 Java 코드를 복사하지 않는다.
- 원작 지도 폴리곤과 시나리오 데이터를 포함하지 않는다.
- UI·명칭·그래픽 자산을 새로 제작한다.
- 장르의 일반적 규칙과 공개적으로 관찰 가능한 플레이 구조만 벤치마킹한다.
