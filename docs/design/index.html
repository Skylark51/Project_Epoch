고대 동아시아
대전략 시뮬레이션

Project Epoch는 한반도·중국·일본을 중심으로 촌락과 지역 세력에서 출발하여 국가와 왕조를 건설하는 장기 대전략 게임이다. 본 문서는 아이디어 수집장이 아니라, 개념의 정의·작동 규칙·시스템 관계·구현 기준을 일관된 형식으로 확정하기 위한 공식 설계 원본이다.

문서 상태: 구조 확정 / 세부 정의 작성 중기준 브랜치: main최종 목표: 배포판 설계 기준서
문서 작성 단위
각 세부 항목은 ① 정의 ② 설계 목적 ③ 구성 요소 ④ 작동 규칙 ⑤ 타 시스템과의 관계 ⑥ 예외와 경계 조건 ⑦ UI 표현 ⑧ 구현 단위 ⑨ 확정 상태의 순서로 기술한다.

역사적 개연성

실제 지리·시대·정치 구조를 기초로 하되, 플레이 결과는 대체 역사로 전개될 수 있다.

전략적 선택

정복 자체보다 통치·보급·정통성·민심·외교의 누적 결과가 국가의 성패를 결정한다.

명시적 정의

국가, 타일, 프로빈스, 도시, 종속국 등 모든 핵심 용어는 구현 전에 상호 배타적으로 정의한다.

배포판 지향

각 시스템은 재미뿐 아니라 저장 안정성, UI 가독성, 성능, 테스트 가능성을 함께 충족해야 한다.

현재 확정된 핵심 원칙
종교는 필수 시스템이지만 동급 종교 간 기능적 우열을 두지 않는다. 명분 없는 전쟁은 허용하되 정통성·민심·외교·점령 통치 비용을 부과한다. 종속국은 자율적으로 운영되지만 충성도와 상대 국력에 따라 종주국 명령을 지연·축소·거부하거나 반란을 일으킬 수 있다. 전투는 세부 실시간 조작보다 편성·지형·병종·사기·지휘관·보급의 전략적 결과를 중심으로 처리한다.
