Project Epoch

고대 동아시아의 소규모 도시국가에서 출발해 도시·영토·군사·외교·경제·정치·문화·종교를 운영하고 국가와 왕조를 형성하는 지도 기반 턴제 대전략 시뮬레이션.

질문 1–30 통합2026-07-29인터페이스 구현 기준본

문서 상태

질문 1–30의 확정 사항을 실제 게임 파일 수정에 사용할 수 있도록 시스템·UI 명세로 통합했다. 수치와 세부 밸런스는 프로토타입 검증 후 조정하되 구조적 결정은 개발 기준으로 사용한다.

질문 1–10 확정

1–10. 게임 기반 체계

게임 정체성. 고대 동아시아의 도시국가에서 출발하는 지도 기반 턴제 대전략 게임이다.
  • 시작은 핵심 도시 하나와 작은 초기 영향권이다.
  • 영향권은 자국계 인구·문화·행복도·수도·군주 상주 효과로 성장한다.
  • 경합 타일은 영향력이 높은 국가가 확보하며 국경은 자동 형성된다.
  • 타일 귀속이 바뀌면 농장·광산·도로·요새 등 시설도 이전된다.
  • 도시 전향은 복수 조건이 장기 누적될 때만 특별 사건으로 발생한다.
  • 행복도·안정도·물리적 통제력은 별도 변수다.
  • 행복도와 안정도는 도시별로 관리하고 국가 평균을 함께 표시한다.
  • 턴 단위는 1개월 또는 1계절 후보이며 현재 권장안은 1계절이다.
확정

11. 통치 위임과 자동 집행

정의. 자동 통치는 직접 통치보다 정밀도와 대응 속도가 약간 낮지만 정상적인 장기 성장이 가능하다.
위임 수준: 직접 통치 · 방침 위임 · 완전 자율
확정

12. 지방 통치 위험

정의. 부패와 반역은 수도 거리, 장기 위임, 낮은 행복도, 높은 불안도, 약한 중앙 행정력 등 복수 조건이 중첩될 때 발생한다.
확정

13. 국가 형태별 임명

정의. 부족국가·봉건체제·군사총독제·군현제 등 국가 형태에 따라 지방 통치자 임명 방식이 달라진다.
확정

14. 직접 통치 한도

정의. 직접 관리 가능한 도시 수에는 절대적 상한을 두지 않는다.
확정

15. 원거리 직접 명령

정의. 정상 편입 도시는 거리와 관계없이 직접 명령이 즉시 적용되며 전쟁 중 임시 점령지만 예외다.
확정

16. 점령지 소유권

정의. 평화협정에 의한 공식 이전 또는 지속적인 군사 통제로 소유권을 확보한다.
확정

17. 군사 통제 영토의 단계적 편입

정의. 점령 직후부터 운영은 가능하지만 지속 점령과 통치를 거쳐야 완전한 소유권 효과를 얻는다.
  1. 점령 직후: 낮은 세수·생산, 높은 저항
  2. 지속 통제: 주둔군·군정·식량·치안 확보
  3. 사실상 편입: 일반 도시 수준 운영, 외교적 분쟁은 잔존
확정

18. 피점령지 주민 융화

정의. 정치적 충성, 시민적 편입, 문화적 융화는 정책 강도·기간·성공도에 따라 차등 변화한다.
확정

19. 융화 정책 적용 단위

정의. 융화 정책은 도시마다 개별 지정한다.
확정

20. 융화 정책 변경

정의. 정책은 일정 기간 유지되어야 하며 잦은 변경은 주민 불신과 안정도 하락을 발생시킨다.
확정

21. 사용자 설정형 상단 정보 바

정의. 핵심 정보만 기본 표시하고 플레이어가 항목을 추가·제거·재정렬한다.

기본 항목은 연도·계절, 국고, 핵심 자원, 전쟁 상태, 긴급 알림 수, 턴 종료 버튼이다. 인구·행복도·안정도·행정력·정통성·군사력·반란 위험 도시 수 등은 선택적으로 추가한다.

  • 드래그 순서 변경
  • 아이콘형·숫자형 선택
  • 공간 부족 시 자동 축약
  • 구성 저장 및 복원
  • 숨긴 항목도 위험 상태는 별도 경고
확정

22. 우측 고정 도시 패널

정의. 도시를 선택하면 화면 우측에 고정 패널이 열리고 선택 도시 정보가 즉시 갱신된다.

도시명, 소유국, 통치자, 인구, 행복도, 안정도, 생산, 식량, 세수, 건설 대기열, 주둔군, 융화 정책, 자동 통치, 반란·전향 위험을 표시한다.

탭: 개요 · 인구 · 경제 · 건설 · 군사 · 통치 · 문화·융화
확정

23. 도시 패널 너비

정의. 기본 너비는 고정하고 정보량이 많은 상세 탭에서만 자동 확장한다.

개요로 돌아오면 기본 너비로 복귀하고 카메라 중심은 패널 변화에 맞춰 보정한다.

확정

24. 지도 위 도시 상시 정보

정의. 도시명, 소유국 색상, 발전 상태를 항상 표시하며 수도는 별도 시각 언어로 강조한다.

수도는 왕관·옥새·궁전 표식, 확대된 배너, 수도 전용 중심 건물 또는 강조 테두리로 구분한다.

확정

25. 건물의 도시 외형 반영

정의. 건물은 개별 아이콘을 모두 상시 노출하지 않고 도시 전체 외형에 누적 반영한다.
건설 성격외형 변화
시장·농업민가·상점·창고 밀도 증가
병영·성벽성곽·방어 시설 강화
관청·궁전중심 행정 건물 확대
항구부두·선박·창고 추가
종교·문화사원·제단·학당·광장 추가
확정

26. 지도 확대·이동·입력

정의. 전략·지역·근접의 3단계 정보 구조와 마우스 휠 연속 확대를 함께 지원한다.
  • 마우스 휠 확대·축소
  • 3단계 즉시 전환 버튼
  • 방향키·WASD 지도 이동
  • 가운데 버튼 드래그
  • 화면 가장자리 이동
  • 미니맵 클릭 이동
확정

27. 선택 도시 순환

정의. 도시 선택 상태에서 좌우 방향키는 현재 도시 목록 정렬 순서에 따라 이전·다음 도시를 선택한다.

기본은 서쪽→동쪽, 같은 경도대에서는 북쪽→남쪽이다. 정렬 기준을 도시명·인구·발전도·행복도·안정도·세수·생산력·반란 위험·편입 시점·수도 거리 등으로 바꾸면 순환 순서도 함께 바뀐다.

  • 카메라 자동 이동
  • 우측 패널 즉시 갱신
  • 현재 탭 유지
  • 끝에서 처음으로 순환
확정

28. 도시 목록과 전체 관리 창

정의. 우측 패널에는 간략 목록을 제공하고 세부 비교·대량 관리는 전체 화면 도시 관리 창에서 수행한다.

검색, 필터, 정렬, 다중 선택, 일괄 정책 변경, 표시 열 설정, 열 너비 조절, 구성 저장을 지원한다. 목록 정렬은 좌우 방향키 도시 순환과 연동한다.

확정

29. 사용자 설정형 알림과 긴급 예외

정의. 사건 종류별 표시 방식을 설정하되 최상위 긴급 사건은 강제 강조한다.
단계예시기본 처리
정보건설 완료·교역 수익알림 목록
주의식량 감소·행복도 악화목록+지도 아이콘
경고반란 위험 급증·적군 접근배너+소리
긴급도시 함락·반란·수도 포위자동 일시정지+중앙 경고
결정 필요평화 제안·후계자·최후통첩응답 전 진행 제한

반복 알림은 묶고 같은 도시의 여러 경고는 도시 위기 카드로 통합한다. 클릭하면 관련 위치로 이동한다.

확정

30. 턴 종료 검증

정의. 긴급하거나 필수적인 미처리 항목만 턴 종료를 차단하고 나머지는 경고 후 종료할 수 있다.

종료 차단

기한 만료 외교 제안, 계승·섭정 결정, 수도 함락·국가 붕괴 위험, 즉시 선택 사건, 필수 시나리오 결정, 명백한 핵심 군단 명령 누락.

경고 후 종료 가능

빈 건설 대기열, 신규 점령지 정책 미지정, 자원 미사용, 일반 부대 미이동, 행복도·안정도 악화, 경미한 외교 기회.

자동화된 항목은 경고에서 제외하고 경고창에서 관련 위치로 즉시 이동할 수 있어야 한다.
