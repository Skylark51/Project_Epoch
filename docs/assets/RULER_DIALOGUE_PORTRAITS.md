# 군주 대화 초상 규격

## 목적

군주 초상은 정지 이미지가 아니라 대화 중 눈과 입이 움직이는 30프레임 스프라이트 시트로 관리한다.

## 파일 규격

- PNG 원본 기준
- 5열 × 6행
- 프레임당 64 × 64 px
- 전체 320 × 384 px
- 총 30프레임
- 에셋 위치: `assets/portraits/rulers/<country>/`

현재 GitHub 연결 환경에서는 PNG 데이터를 여러 `.b64` 조각으로 저장한다. 런타임은 조각을 순서대로 결합하고 `Image.load_png_from_buffer()`로 초상을 복원한다. 게임 코드는 외부 네트워크나 별도 변환 작업을 요구하지 않는다.

## 런타임 구간

| 프레임 | 용도 |
|---|---|
| 1–8 | 대기·호흡 |
| 9–12 | 눈 깜빡임 |
| 13–24 | 대화 중 입 모양 |
| 25–30 | 대화 종료·안정 자세 |

## 데이터 연결

`data/dialogue/rulers.json`에서 국가 ID와 군주 이름, 초상 데이터 조각, 프레임 크기, 재생 속도, 대사를 연결한다. 새 군주를 추가할 때 UI 코드는 수정하지 않고 데이터와 동일 규격의 시트만 추가한다.

## 현재 구현

고구려 선택 시 `군주 접견` 버튼 또는 `D` 키로 광개토대왕 대화를 열 수 있다. 문장이 출력되는 동안 발화 프레임을 재생하고, 출력이 끝나면 호흡·깜빡임 루프로 전환한다. `Enter`는 현재 문장을 완전히 표시하거나 다음 문장으로 진행하고, `Escape`는 접견을 종료한다.
