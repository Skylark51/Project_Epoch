# 광개토대왕 군주 대화 구현

## 플레이 방법

1. 고구려로 게임을 시작한다.
2. 게임 화면 상단의 `♛ 군주 접견 D` 버튼을 누르거나 `D` 키를 누른다.
3. 대사가 타이프라이터 방식으로 출력되는 동안 군주 초상의 입 모양이 움직인다.
4. `Enter`를 누르면 현재 문장을 즉시 표시하고, 다시 누르면 다음 문장으로 진행한다.
5. `Escape` 또는 `접견 종료`를 누르면 대화를 닫는다.

## 구성

- `src/ui/ruler_dialogue_overlay.gd`: 대화창, 타이프라이터, 프레임 재생
- `data/dialogue/rulers.json`: 국가별 군주와 대사 정의
- `assets/portraits/rulers/goguryeo/`: 광개토대왕 30프레임 초상 데이터
- `tests/ruler_dialogue_test_runner.gd`: 장면 연결과 30프레임 계약 검증

초상 애니메이션은 대사 출력 중 발화 프레임을 순환하고, 대기 중에는 호흡·눈 깜빡임·안정 자세 프레임을 재생한다.
