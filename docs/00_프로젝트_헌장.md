# Project Epoch 프로젝트 헌장

## 목표
Province 기반 역사 대전략 게임의 즉각적인 지도 피드백과 높은 반복 플레이성을 유지하면서, UI 불편·AI 비합리성·후반 스노우볼·세이브 불안정 문제를 구조적으로 해결한 독립 상업 게임을 제작한다.

## 벤치마킹 원칙
- AoCII 실행본은 동작과 데이터 조직을 연구하기 위한 참고 자료다.
- 역컴파일 코드, 원본 지도 좌표, 이미지, 음악, 국가 데이터는 제품에 복사하지 않는다.
- Province, 시나리오, 데이터 중심 설계, 지도 LOD 등 일반적인 설계 패턴만 독립 구현한다.
- 모든 신규 코드와 자산은 출처와 라이선스를 기록한다.

## 제품 원칙
1. 지도에서 결과가 즉시 보일 것.
2. 5분 안에 기본 플레이를 이해할 수 있을 것.
3. 소국 플레이에도 독자적인 생존·성장 전략이 있을 것.
4. AI의 판단 근거를 디버그 화면에서 설명할 수 있을 것.
5. 콘텐츠를 코드와 분리해 모딩 가능하게 만들 것.
6. 1,000턴 이상에서도 성능과 저장 안정성을 유지할 것.
