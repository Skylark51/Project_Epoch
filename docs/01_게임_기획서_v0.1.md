# Project Epoch 게임 기획서 v0.1

## 1. 게임 개요
- 장르: Province 기반 역사 대전략 / 국가 경영 시뮬레이션
- 플랫폼: Windows, Steam
- 플레이: 싱글플레이 우선
- 시간 방식: 명령 예약 후 동시 해결되는 턴제
- 첫 출시 범위: 하나의 지역 지도, 20~40개 국가, 300~600개 Province, 100~150년

## 2. 핵심 플레이 루프
상황 파악 → 정책·외교·군사 명령 → 턴 해결 → 지도 변화와 사건 발생 → 새로운 목표 설정

## 3. 핵심 자원
- 국고: 건설, 외교, 군대 유지
- 행정력: 영토 통합과 정책 실행
- 정통성: 반란과 외교 신뢰
- 인력: 징병과 경제활동의 공통 기반
- 영향력: 외교·속국·연방 행동

## 4. Province 모델
각 Province는 소유국, 통제국, 인구, 경제, 문화, 종교, 지형, 기반시설, 불만, 보급, 인접 Province를 가진다.

## 5. 전쟁
군대는 Army 단위로 이동한다. 병력 수만이 아니라 사기, 보급, 지형, 지휘관, 전투 폭, 후퇴 경로를 계산한다. 전쟁 목표와 점령 비용을 분리한다.

## 6. 외교
관계 수치 하나 대신 신뢰, 공포, 위협, 경제 의존, 영토 분쟁, 이념 친화도를 분리한다. AI는 전쟁과 조약의 이유를 설명 가능한 점수로 기록한다.

## 7. 내정과 확장 제약
확장 페널티는 임의 수치가 아니라 행정 거리, 문화 통합, 지역 엘리트, 부패, 주둔 비용으로 발생한다. 지방 자치와 중앙집권은 서로 다른 장단점을 가진다.

## 8. UI 개선
- Province 드래그 다중 선택
- 우클릭 문맥 메뉴
- 툴팁에 계산식과 원인 표시
- 검색 가능한 국가·도시·Province 목록
- 경고 중요도 분류
- 반복 명령 자동화
- 전쟁 선포 전 예상 참전국·비용·승률 표시

## 9. 반복 플레이 장치
- 국가별 전략적 제약
- 절차적으로 조합되는 사건
- 지도자 성향과 승계
- 동적 동맹과 세력 균형
- 소국 전용 외교·무역·용병 플레이
- 업적 및 캠페인 목표

## 10. MVP 완료 기준
1. Province 선택과 지도 렌더링
2. 국가 3개 이상과 소유권 표시
3. 턴 진행과 경제 갱신
4. 군대 생성·이동·전투
5. 기본 AI 턴
6. 저장·불러오기
7. 100턴 자동 시뮬레이션 무오류
