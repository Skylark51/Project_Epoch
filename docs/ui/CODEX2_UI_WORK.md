# Project Epoch 지도·UI 작업

## 구현 범위

- 시작 → 시나리오 → 국가 선택 → 인게임으로 이어지는 화면 상태 흐름
- Container와 anchor 기반 1280×720 / 1920×1080 대응 레이아웃
- 상단 국가 지표, 좌측 지도 모드·검색, 우측 Province·행동, 하단 명령·로그·전쟁 패널
- Province 좌클릭 선택, 휠 마우스 기준 줌, 가운데/우클릭 드래그 패닝
- 정치·외교 관계·전쟁·경제·인구·개발도·인력·안정도·반란 위험·지형·요새 모드와 범례
- 모집·이동·공격 예약, 지도 화살표, 명령 큐 취소
- 외교 행동 패널과 지도 Province 요구형 평화 협상 패널
- 중요도·분류 필터를 가진 최대 120개 이벤트 로그
- 고전 지도와 현대 전략 UI를 혼합한 공용 Godot Theme

## 구조

`src/main.gd`는 화면 전환과 UI 조립·표시만 담당합니다. `StrategicMap`은 커스텀 CanvasItem 그리기와 지도 입력 상태를 담당하고, `StrategyGateway`는 `GameSession` 공개 스냅샷을 UI 표시 구조로 변환하고 검증된 명령을 코어 큐에 전달합니다. UI는 소유권·전투·경제 상태를 직접 변경하지 않습니다.

지도는 Province마다 Control 노드를 만들지 않고 한 Control에서 폴리곤을 그립니다. 선택 판정은 160 world-unit 공간 버킷을 사용하며, 데이터 변경 때만 재구축합니다. 수치 지도는 8–92 분위수 범위로 정규화하여 극단값 영향을 줄입니다. 줌 단계에 따라 라벨과 아이콘을 생략합니다.

## 입력 상태

`IDLE`, `CHOOSING_MOVE_TARGET`, `CHOOSING_ATTACK_TARGET`, `SELECTING_PEACE_TERMS`, `DRAGGING_MAP`, `MODAL_OPEN`을 명시적으로 사용합니다. 드래그가 끝나면 드래그 전 명령 준비 상태로 복원되어 이동 목적지를 고르던 중 패닝해도 명령이 풀리지 않습니다. Window는 exclusive 모달로 열리고 지도 Control은 UI 입력을 가로채지 않습니다.

## 조작

- 좌클릭: Province 선택 또는 준비된 명령 목적지 선택
- 우클릭: 목적지 선택 / 드래그 시 패닝
- 가운데 버튼 드래그: 패닝
- 휠: 마우스 위치 기준 줌
- `M`: 이동 준비, `A`: 공격 준비, `R`: 모집, `Space`: 턴 실행, `Esc`: 명령/모달 취소
- 텍스트 입력 포커스 중에는 지도 단축키가 작동하지 않습니다.

## 검증

Godot 4.6.3 Standard에서 headless editor parse와 자동 스모크 테스트를 수행했습니다. 1280×720 및 1920×1080에서 지도 영역, 우측 패널, 하단 패널이 겹치지 않는지 검사했습니다. 시작 화면 선표시, Province 선택, 줌, 패닝 상태 복원, 11개 지도 모드, 모집·이동·취소, 외교·평화 창, 로그 상한을 통과했습니다.

## 자산 및 한계

AoCII 원본 패키지는 작업 경로에서 발견되지 않아 원작 그래픽을 사용하지 않았습니다. UI는 Godot 기본 폰트·도형·색상으로 독립 제작했으며 외부 자산 의존성이 없습니다. 통합 브랜치에서는 턴 처리·전쟁·경제·AI 계획·자동 저장이 실제 코어를 통해 실행됩니다. 일부 확장 외교 행동과 수도 이전·점령지 관리는 코어 지원 전까지 거부 메시지를 표시합니다.
