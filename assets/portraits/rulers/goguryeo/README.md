# 광개토대왕 대화 초상

게임 내 군주 대화창에서 사용하는 30프레임 스프라이트 시트다.

- 배열: 5열 × 6행
- 프레임: 64 × 64 px
- 복원된 전체 이미지: 320 × 384 px
- 순서: 왼쪽에서 오른쪽, 위에서 아래
- 1–8: 기본 호흡
- 9–12: 눈 깜빡임
- 13–24: 발화
- 25–30: 안정 자세 복귀

GitHub 연결 환경의 바이너리 업로드 제약 때문에 PNG 원본은 `gwanggaeto_dialogue_30f.part00.b64`부터 `part08.b64`까지 분할 저장한다. `RulerDialogueOverlay`가 실행 중 조각을 결합하고 PNG를 메모리에서 복원한다.

초상은 실존 인물의 실제 얼굴 복원이 아니라, 고구려 후기 왕실·무장 이미지를 참고한 게임용 창작 표현이다.
