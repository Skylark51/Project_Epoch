# Project Epoch

Province 기반 역사 대전략 게임 프로토타입입니다. 역사의 시대 계열의 빠른 영토 확장과 시나리오 중심 턴 구조를 벤치마킹하되, 코드·지도·UI·데이터는 독립적으로 제작합니다.

## 실행

1. `git pull origin main`
2. 프로젝트 폴더의 `.godot` 캐시를 삭제
3. Godot 4.x Standard에서 `project.godot` 열기
4. `F5` 실행

## 현재 플레이 흐름

1. 우측에서 플레이 국가 선택
2. 지도에서 자국 Province 클릭
3. 병력 모집 또는 이동 명령 준비
4. 이동 명령 준비 후 인접 Province 클릭
5. 외국 공격 전 외국 Province를 선택하고 전쟁 선포 예약
6. `턴 실행`으로 플레이어와 AI 명령 동시 처리

## 구현된 기능

- 6개 Province 플레이 지도
- JSON 기반 국가·Province·시나리오·외교 데이터
- 플레이 국가 선택
- 정치·경제·인구·관계 지도 모드
- 모집·이동·전쟁·평화 명령 예약
- 동시 턴 처리
- 지형·요새·기술을 반영한 간이 전투
- 영토 점령
- 세입·군대 유지비·인력 회복
- 기본 AI 모집·전쟁·공격

## 안정화 구조

- 실행 로직을 `src/main.gd` 하나로 통합했습니다.
- 지도와 UI를 `src/main.tscn`에 정적으로 배치했습니다.
- 스크립트가 실패해도 기본 지도와 UI는 표시됩니다.
- 기존 `GameState`, `DiplomacyState`, `TurnProcessor`, `StrategyAI`, 동적 지도 모듈은 제거했습니다.
