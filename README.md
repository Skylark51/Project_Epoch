# Project Epoch

Province 기반 역사 대전략 게임의 독립 프로토타입입니다. AoCII의 데이터 중심 지도·시나리오·턴제 구조를 벤치마킹하되 코드, 지도, UI, 게임 규칙은 독립적으로 개발합니다.

## 실행

1. Godot 4.x Standard에서 저장소의 `project.godot`를 연다.
2. `F5` 또는 우측 상단 실행 버튼을 누른다.
3. Godot 3.x가 아니라 Godot 4.x를 사용한다.

## 현재 플레이 흐름

1. 우측 상단에서 플레이 국가를 선택한다.
2. 자국 Province를 좌클릭한다.
3. `병력 10 모집 예약`으로 모집 명령을 추가한다.
4. `이동 명령 준비`를 누른 뒤 인접 Province를 우클릭한다.
5. 외국을 공격하려면 먼저 해당 국가 Province를 선택하고 `전쟁 선포 예약`을 누른다.
6. 지도에 표시된 예약 명령을 확인한다.
7. `턴 실행`을 눌러 플레이어와 AI 명령을 함께 처리한다.

## 조작

- 좌클릭: Province 선택
- 우클릭: 준비된 이동 명령의 목적지 지정
- 마우스 가운데 버튼 드래그: 지도 이동
- 마우스 휠: 지도 확대·축소
- 정치·경제·인구·관계 버튼: 지도 모드 전환

## AoCII식 핵심 구조

```text
Scenario JSON
├─ 시작 날짜
├─ 플레이 국가
└─ 외교 초기값

GameState
├─ 국가
├─ Province
├─ 군대
├─ 외교·전쟁 상태
└─ 명령 큐

TurnProcessor
├─ 외교 단계
├─ 모집 단계
├─ 이동·전투 단계
├─ 경제 단계
├─ 성장 단계
└─ 날짜 진행
```

## 구현된 기능

- JSON 기반 국가·Province·시나리오·외교 데이터
- Province 폴리곤 지도
- 수도 표시
- 정치·경제·인구·관계 지도 모드
- Province 선택과 상세 정보
- 지도 패닝·줌
- 플레이 국가 전환
- 동시 명령형 턴 큐
- 예약 모집과 이동 경로 표시
- 전쟁 선포와 평화 제안
- 국가 관계 및 전쟁 점수
- 지형·요새·기술·개발도를 반영한 간이 전투
- 세입·군대 유지비·인력 회복
- 연간 인구·경제 성장
- 외교·모집·군사 판단으로 분리된 기본 AI

## 저장소 원칙

- 원작 실행 파일, 역컴파일 코드, 지도 및 그래픽 자산을 포함하지 않는다.
- 분석 결과는 설계 원리와 문제점 개선에만 사용한다.
- 게임 코드와 데이터는 상업 출시 가능한 독립 구현으로 유지한다.
