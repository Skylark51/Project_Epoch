# Project Epoch

Province 기반 역사 대전략 게임의 독립 프로토타입입니다. AoCII의 데이터 중심 지도·시나리오 구조를 벤치마킹하되 코드, 지도, UI, 게임 규칙은 독립적으로 개발합니다.

## 실행

1. Godot 4.x Standard에서 저장소의 `project.godot`를 연다.
2. `F5` 또는 우측 상단 실행 버튼을 누른다.
3. Godot 3.x가 아니라 Godot 4.x를 사용한다.

## 현재 플레이 루프

1. 우측 패널에서 플레이 국가를 선택한다.
2. 지도에서 자국 Province를 클릭한다.
3. `병력 10 모집`으로 군대를 증원한다.
4. `이동/공격 준비`를 누른다.
5. 인접 Province를 마우스 오른쪽 버튼으로 클릭한다.
6. 병력과 지형·요새 수치에 따라 이동 또는 전투가 처리된다.
7. `다음 턴`을 눌러 세입, 인력 회복, 인구·경제 성장과 AI 증원을 처리한다.

## 조작

- 좌클릭: Province 선택
- 우클릭: 준비된 이동·공격 명령의 목적지 지정
- 마우스 가운데 버튼 드래그: 지도 이동
- 마우스 휠: 지도 확대·축소
- 정치·경제·인구 버튼: 지도 모드 변경

## 구현된 기능

- JSON 기반 국가·Province 데이터 로딩
- 폴리곤 Province 지도 렌더링
- 정치·경제·인구 지도 모드
- Province 선택과 상세 정보
- 지도 패닝 및 줌
- 플레이 국가 전환
- 병력 모집과 국고·인력 소모
- 인접 Province 이동
- 지형·요새를 반영한 간이 전투와 점령
- 계절 단위 턴 진행
- 세입, 인력 회복, 인구·경제 성장
- 비플레이 국가의 기본 병력 증원 AI
- 전략 로그
