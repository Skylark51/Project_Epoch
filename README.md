# Project Epoch Prototype

Province 기반 역사 대전략 게임의 독립 프로토타입입니다.

## 실행
1. Godot 4.x에서 이 폴더의 `project.godot`를 연다.
2. F6 또는 F5로 실행한다.
3. Province를 클릭해 정보를 확인하고 `다음 턴`을 눌러 경제 갱신을 확인한다.

## 현재 기능
- JSON 기반 국가·Province 데이터 로딩
- 폴리곤 지도 렌더링
- 마우스 선택과 호버
- 소유국 색상 표시
- 턴 진행과 세입 계산
- 상세 정보 및 턴 로그
